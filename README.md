# Estrutura-de-Dados-I
Repositório dedicado a armazenar os conteúdos abordados durante a matéria de Estrutura de Dados durante o terceiro semestre da faculdade de Bacharelado em Ciência da Computação. 
## Conteúdos Abordados:
- Lista Estatica;
- Fila Estatica;
- Pilha Estatica;
- Deque Estatica;
- Alocações Dinamicas;
- Listas, Pilhas, Filas e Deques Dinâmicas;
- Lista Ponteiro a Ponteiro;
- Lista Ponteiro-Ponteiro Dinâmica;
- Lista Circular;
- Lista Duplamente Encadeada.
